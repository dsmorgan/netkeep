A one-line installer for macOS: `curl -fsSL https://github.com/dsmorgan/netkeep/releases/latest/download/install.sh | sh`. It installs uv into `~/.local/bin` if it's missing (uv's installer pinned by version and SHA-256), checks the release's constraints file against its `SHA256SUMS`, installs that netkeep release as a uv tool with uv's own Python 3.12, then runs `netkeep setup`. It prints each step, has `--dry-run`, never uses `sudo`, never writes outside your home directory, and runs nothing unless it downloaded whole. Each release attaches it with its checksum. The README now leads with it, with a download-verify-run alternative.
