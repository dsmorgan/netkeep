**Start Chrome** on the dashboard and the LinkedIn page's **Browser** card starts netkeeper's own Chrome, with netkeeper in its own window, or opens netkeeper in it when it's running, and says how it went in plain words, refusals included. The card shows whether netkeeper's Chrome is running, and the button is disabled while a run uses the browser or a start is under way. A new setting, **Start netkeeper's Chrome when netkeeper starts** (off by default, `linkedin.start_chrome_at_startup`), starts it once `netkeeper serve` is listening, so with **Run at login** on, Chrome starts when you log in. It starts nothing when netkeeper's Chrome is already running or a run holds the browser. Both use the one launcher, which never touches a Chrome on another profile. You still sign in to LinkedIn yourself.
