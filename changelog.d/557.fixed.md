A profile (enrichment) headline now wins over the connection card's: the sync overwrites it only when the card's own text changed since the sync last saw it, so repeat syncs no longer flip the headline back or write a snapshot. Migration 0045 adds `contacts.headline_via` and `contacts.card_headline_seen`.

A contact enriched before this upgrade has no recorded path, so its first sync after the upgrade still writes the card headline (one snapshot); the next enrichment sets the profile headline, and from then on the rule holds.
