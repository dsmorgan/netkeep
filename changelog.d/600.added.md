Settings has a "Start netkeep when I log in" switch, and `netkeep login-item on|off|status` does the same: it installs or removes a per-user launchd agent that runs `netkeep serve`, with its state read from the plist and `launchctl`. Each data directory gets its own agent. It replaces `scripts/install-launchd.sh` and `scripts/serve-launchd.sh`, which are removed; the agent now runs the installed `netkeep` directly, so the 5 MB rotation of `serve.log` and `serve.err.log` at start is gone (they hold only warnings and crashes).

If you installed the login item with `scripts/install-launchd.sh`, run `netkeep login-item on` once from a terminal, or press **Repair** in Settings, Run at login. The script is gone, so the old agent can no longer start; this replaces it (and keeps its `--host` and `--port`).
