Settings has a "Start netkeeper when I log in" switch, and `netkeeper login-item on|off|status` does the same: it installs or removes a per-user launchd agent that runs `netkeeper serve`, with its state read from the plist and `launchctl`. Each data directory gets its own agent. It replaces `scripts/install-launchd.sh` and `scripts/serve-launchd.sh`, which are removed; the agent now runs the installed `netkeeper` directly, so the 5 MB rotation of `serve.log` and `serve.err.log` at start is gone (they hold only warnings and crashes).
