A release workflow: a `vX.Y.Z` tag publishes netkeep to PyPI with trusted publishing from a protected `release` environment, with no stored token, and attaches the wheel, the sdist, the constraints file and `SHA256SUMS` to an immutable GitHub release. Every release, and every pull request, installs the built wheel as a uv tool with the constraints file on an Intel and an Apple-silicon Mac. On Intel Macs, cryptography stays at 48.x, the last version with Intel wheels.
