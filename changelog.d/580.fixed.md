Each data directory now keeps its Keychain secrets under its own service, so a second install on the same Mac (another `NETKEEP_DATA`) can no longer read, overwrite or delete the first one's Gmail OAuth client and token. The default data directory keeps the service `netkeep`, so existing installs keep their secrets; any other directory uses `netkeep@<hash of its path>`, and `NETKEEP_KEYCHAIN_SERVICE` overrides both. `netkeep config show`, `netkeep gmail status` and the Gmail page's Connection card show the service in use.

If you already run netkeep from a data directory other than the default, it no longer finds the Gmail client and token it stored before: connect Gmail again from that directory, or set `NETKEEP_KEYCHAIN_SERVICE=netkeep` for it if it is the only install on the Mac.
