Each data directory now keeps its Keychain secrets under its own service, so a second install on the same Mac (another `NETKEEPER_DATA`) can no longer read, overwrite or delete the first one's Gmail OAuth client and token. The default data directory keeps the service `netkeeper`, so existing installs keep their secrets; any other directory uses `netkeeper@<hash of its path>`, and `NETKEEPER_KEYCHAIN_SERVICE` overrides both. `netkeeper config show`, `netkeeper gmail status` and the Gmail page's Connection card show the service in use.

If you already run netkeeper from a data directory other than the default, it no longer finds the Gmail client and token it stored before: connect Gmail again from that directory, or set `NETKEEPER_KEYCHAIN_SERVICE=netkeeper` for it if it is the only install on the Mac.
