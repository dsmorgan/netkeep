Rolling back an import no longer deletes an email, phone, link, position or archive message the import added when something changed it afterward. An address you edited or marked bounced, or a message whose summary you edited, now stays, and the rollback's result (`netkeep import rollback`, the API, and the run page) names each row it kept. On a contact the import created, such a change counts as something the contact gained, so the rollback asks for `force` before deleting the contact with it.
