`netkeep setup`, which the installer runs after it installs netkeep: it turns on the login item (pointing at uv's `~/.local/bin/netkeep` shim for a uv tool install, or the checkout's `.venv`, with a note), waits for `serve` to answer, and opens the first-run page in netkeep's Chrome. Run again, it changes nothing that's already right. `netkeep setup --remove` turns the login item off and keeps all data. The login item now points at uv's shim, not the tool environment's own `bin`, for a uv tool install.
