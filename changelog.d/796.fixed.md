Before the Contact info click and the Message click, netkeep now checks that the tab is on LinkedIn itself, not only at the profile's path, and refuses a link whose address Chrome and netkeep could read as two different hosts: one with a backslash, a user name before `@`, an encoded or empty host (`///messaging/compose/…`), or a control character or space. Such a link used to pass the Contact info check, or the Message control's compose check, while Chrome would have opened another site.
