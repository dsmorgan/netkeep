**Start Chrome**, `netkeep open`, and starting `serve` with **Start netkeep's Chrome when netkeep starts** on now bring netkeep's open window to the front when netkeep's Chrome is already showing it, instead of opening another window each time. They open a window only when none is open, or when netkeep can't bring it forward (while a run is using the browser, on setup's first run, or when that check fails). Before it brings anything forward, netkeep still checks that the running Chrome is its own, and it only ever brings forward a window on netkeep's own address, never a run's.
