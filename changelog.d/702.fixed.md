Rolling back an import now undoes only what the import did. A rollback is refused when a contact the import added an address, phone, link or position to has since absorbed another contact in a merge, because deleting that row would take the other contact's copy (and its bounced status) with it. A LinkedIn URN that a CSV row's profile URL taught an existing contact is now recorded by the run and removed by its rollback. Rolling back an archive import keeps the messages the LinkedIn inbox poll has since adopted, and asks for `force` when such a message sits on a contact the archive created. An archive's own `messages.csv` is now read first to decide whose archive it is, and any other messages table whose messages name a different owner is skipped and named in the import's result. So when `messages.csv` names you as the owner, another person's export in the same archive can no longer override it or put their messages on your contacts' timelines.
