The safety scans are stricter. The raw-connection pin now reads anyio's and asyncio's other openers, `_socket` and `socket.SocketType`, and every use of anyio is pinned by site; the network-client pin covers `imaplib`, `poplib`, `nntplib` and `logging.config`. The Gmail never-deletes scan pins each Gmail API request by resource and method, pins the one label change word for word, and catches a held resource, a method read by `getattr`, labels it can't read, and a `TRASH` or `SPAM` string outside the fake. Tests now run in their own working directory, so a `config.toml` in your checkout no longer changes their results.
