A full connections sync whose list hides members no longer stops as `answer_lost` when LinkedIn's last answer arrives without a body and the page then goes quiet. The streamed copy of that last answer now counts the hidden places earlier answers proved, so it stands in when the run accounts for every place the total names. It still adds no slack: a copy that leaves any place unaccounted for, or that was cut short, stays refused, and the refusal now logs how many places the run accounted for.
