`netkeep setup` adds a netkeep icon to your Applications folder, `~/Applications/netkeep.app`, so you can open netkeep from the Dock, Spotlight or Launchpad without a terminal. Clicking it opens netkeep's window the way `netkeep open` does, starting the login item first if `serve` isn't running, and shows a dialog that says what to run if it can't reach netkeep. `netkeep update` rewrites it, Settings › Run at login shows it with a Build or Rebuild button, and `netkeep setup --remove` removes it. It's built on your Mac, never downloaded.
