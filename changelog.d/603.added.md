A support bundle: `netkeep support bundle [--level standard|detailed|full] [--since 7d] [-o file.zip]`, and Settings, Support, which previews each level and downloads the file. One `.zip` with a `README.txt`, a `manifest.json`, versions, settings, posture (from stored state, never a browser check), breakers, the LinkedIn schedule, recent runs, the migration revision and logs. Standard and detailed replace every personal value with a placeholder such as `<email-3>`; full keeps real values and needs a typed or ticked confirmation. No level ever includes a secret. netkeep never uploads the file. See [Reporting a problem](docs/guide/reporting-a-problem.md); the bug report template now asks for the standard bundle and screenshots.
