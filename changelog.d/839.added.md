`make update` updates a checkout in one command: it checks the checkout is on `main` with no uncommitted changes and fast-forwards to `origin/main`, stops the login item, backs up the database, pulls, runs `uv sync --all-extras --frozen`, builds the UI, then starts the login item again and checks that `serve` answers. It stops at the first step that fails and prints where things stand and what to run next. `make setup` installs a new checkout and builds its UI. `netkeep update` in a checkout now points you to `make update`.
