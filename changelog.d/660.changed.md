The browser safety tests now catch dynamic imports and disguised names package-wide. They list every use of `importlib`, `__import__`, `ctypes`, `multiprocessing`, `concurrent`, `pty`, `vars()`, `globals()`, `__dict__`, a module's `__getattr__`, `sys.modules`, `inspect.getmembers` and a `getattr` with a computed name, each with a reason, so a new one fails CI. The importer pins read literal dynamic imports, the process ban adds `multiprocessing`, `ctypes` and `ProcessPoolExecutor`, and a launcher read from `app.state` can only go to `submit_launch`. Test-only; no product behavior changes.
