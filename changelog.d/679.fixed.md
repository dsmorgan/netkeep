With **Start netkeep's Chrome when netkeep starts** on, restarting `serve` while netkeep's Chrome is still running now opens the UI in that Chrome, so you see the UI after every start. The launcher still checks that the running Chrome is netkeep's before it hands off, and `serve` starts nothing when a run holds the browser as it checks, or while a launch is under way. Each restart opens one more window in that case (#678 tracks reusing an open one), except within 5 minutes of the last window a start opened in the same Chrome, so a `serve` that keeps restarting doesn't pile up windows.
