With **Start netkeep's Chrome when netkeep starts** on, restarting `serve` while netkeep's Chrome is still running now opens the UI in that Chrome, so you see the UI after every start. The launcher still checks that the running Chrome is netkeep's before it hands off, and `serve` starts nothing when a run holds the browser as it checks, or while a launch is under way. It brings netkeep's open window there to the front, or opens one when none is open (#678), except within 5 minutes of the last time a start did that in the same Chrome, so a `serve` that keeps restarting doesn't keep taking focus.
