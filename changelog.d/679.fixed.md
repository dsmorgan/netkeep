With **Start netkeep's Chrome when netkeep starts** on, restarting `serve` while netkeep's Chrome is still running now opens the UI in that Chrome, so you see the UI after every start. The launcher still checks that the running Chrome is netkeep's before it hands off, and `serve` still starts nothing while a run holds the browser or a launch is under way. Each restart opens one more window in that case (#678 tracks reusing an open one).
