A run cancelled, or `serve` stopped, while netkeep is attaching to Chrome is recorded as aborted instead of failed with browser_unavailable, so it no longer parks a retry. Typing into the LinkedIn composer now ends partially typed when a later compose option arrives with the last key, as it already did mid-body. The streamed backup copy of a LinkedIn answer is dropped when the request redirects or its read times out, so it can't stand in for a different answer.
