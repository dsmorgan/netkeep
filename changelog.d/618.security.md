The local API now requires a per-install key (#618, ADR 0013), so other programs on your Mac that only speak HTTP can't drive netkeeper. The key lives only in the Keychain. Your browser gets a session cookie (`HttpOnly`, `SameSite=Strict`) instead of the key: the first browser to load the UI after the upgrade connects itself, and another browser connects through the link `netkeeper open` prints. Health, the Gmail OAuth callback and the connect endpoints stay open.
