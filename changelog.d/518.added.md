A run's counts now show how many snapshots it wrote and how many times it changed each job field (headline, title, company, location), in `netkeep linkedin run <id>` and on the run detail page. A new command, `netkeep linkedin field-changes --run <A> [--run <B> ...]`, counts the same for any runs, including older ones, and how many contacts' headlines went back to an earlier value across them. It prints counts only, never a name.
