The Backups settings (`backup.nightly`, `backup.keep`) and the Chrome profile path in `GET /linkedin/browser` belong to the local owner: other users see the settings read-only with a note, a write to them is refused (403), and the browser instructions are 403 for them. One query, `services.users.local_owner`, now decides who the owner and the current user are, and a test fails if a copy returns. A refused (4xx) Settings request is no longer retried.
