Enrichment now reads LinkedIn's missing-profile page as not found. A profile url that doesn't exist answers `200` with a page that has no top card, and the page then moves the tab to `/404/`. That visit used to count as unreadable, so two missing profiles in a row stopped the run and the contact was never marked gone. Now the visit is `NotFound`, spends no scroll, and adds to the contact's not-found streak. The tab's path must be exactly `/404/`, the document must name the missing page, and no profile screen or redirect may have been seen during the visit.
