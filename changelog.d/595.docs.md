ADR 0012 (Accepted 2026-10-17, revised after the maintainer's review) puts the UI, LinkedIn, and setup steps such as Gmail linkage in one netkeep Chrome: the dedicated profile with the debugging port, so you have one place to look. Your everyday Chrome can't serve, because Chrome 136 and later ignore the port on the default user data directory, so no profile inside your everyday Chrome works either. The UI opens as an app window in netkeep's Chrome, one launcher is the only spawn, and runs touch only their own tabs, with follow-ups #632, #633, #634 and the launcher in #636 and the Phase 7 bundled browser in #631. The research and mechanics are in `docs/design/chrome-profiles.md`.

ADR 0013 (a per-install key for the local API, #618) is also Accepted as of 2026-10-17: the first browser still connects by itself, and key rotation is not built for now.
