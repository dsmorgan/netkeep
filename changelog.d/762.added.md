`netkeep serve` checks once a day for a newer netkeep release and the Settings page shows it, with the command to run (`netkeep update`). It asks GitHub for the newest published release, the same request `netkeep update --check` makes, sends nothing about you, and installs nothing. Turn it off with **Check for updates daily** in Settings, Updates, or `[updates] check_daily = false` in `config.toml`. A failed check logs one line and tries again the next day.
