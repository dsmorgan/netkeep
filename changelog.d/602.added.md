`netkeeper serve` and every command now also log to `<data_dir>/logs/netkeeper.log`, which rotates by size and keeps a set number of old files (Settings, Logs; `[logs] max_mb` and `keep`). `netkeeper config show` and the Settings page say where the file is. Values the code knows are personal are marked in the file so a support bundle can redact them. Under the LaunchAgent, `serve.err.log` keeps only warnings, errors and crashes, and the agent rotates `serve.log` and `serve.err.log` at each start once they pass 5 MB.
