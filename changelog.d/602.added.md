`netkeep serve` and every command now also log to `<data_dir>/logs/netkeep.log`, which rotates by size and keeps a set number of old files (Settings, Logs; `[logs] max_mb` and `keep`). Processes that share the file take a lock to write and rotate, so no line is lost. The file is `0600` in a `0700` directory. `netkeep config show` and the Settings page say where the file is. Values the code knows are personal, including data-directory paths and campaign names, are marked in the file so a support bundle can redact them. Database errors no longer quote bound values. `openapi export` and `version` write no log file, and `make gen-client` uses a scratch data directory. Under the LaunchAgent, `serve.err.log` keeps only warnings, errors and crashes, and the agent rotates `serve.log` and `serve.err.log` at each start once they pass 5 MB, keeping both private.
